## 产品规则

相同原文可能包含多件事，因此保留新候选。若待审核候选与已批准或人工修改过的条目具有相同身份、非空会话、功能、范围和角色集合，且证据消息 ID 重叠，则提示“与已核对的记忆引用了相同原文，请对照确认”，展开显示原文结论。

这只是证据关联，不判定语义重复或矛盾，不强制合并、不自动批准、不覆盖人工内容。无共同证据 ID 的增量变化不猜测关联。不同身份、会话、功能或角色范围不展示关联摘要，避免额外扩大可见范围；它不替代未来公共版鉴权。
