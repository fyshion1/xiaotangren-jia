# 桌宠陪伴、主动招呼与中文唤醒

更新：2026-10-21；时间使用 Asia/Shanghai。

## 陪伴方式

界面使用「悄悄陪着」「我忙一会」「陪我歇会」「来陪我呀 · 15／30／60分」，让入口更亲近。选择「来陪我呀」允许这段时间内主动招呼，会产生正常聊天模型用量；主动消息只显示文字，不突然播放声音。

作息规则依据个人数据库 `02_AI工作层/睡眠摘要/睡眠摘要_2026-10-12.md`，不是个人记忆库。原摘要待审核、记录截至10月11日，不能据此判断今天是否睡着。程序只使用派生规则，不向模型注入整份摘要。

默认悄悄陪着；02:00–14:00标记作息保护。明确选择限时陪伴可以覆盖保护时段。许可按绝对时间到期，重启不续期；休息状态需手动解除，解除后有20分钟缓冲。状态保存到 Electron userData/presence.json，异常时回到默认状态。手动聊天、通话及已确认的到期提醒保留原行为。

## 主动闲聊队列

后端 `/pet/companion/social` 和桌宠主进程共同处理；主进程每30秒检查，窗口可见、没有正在聊天或通话、且处于许可时间才会请求。首次会话初始化后等待约5分钟，再视轮询和模型耗时送出。

队列与冷却保存在当前后端数据库的 `pet_social_state`、`pet_social_queue`，跨重启保留：

- 全局每天最多3次生成尝试，失败或模型决定不说也占用次数，不自动重试付费生成。
- 同会话至少间隔90分钟，同角色至少间隔3小时。
- 发出一次后等待用户真实回复，用户未回应就不连续打扰。
- 草稿2小时过期；发送前重新核对许可、身份、会话、角色及最新用户消息。过期或上下文已变化则丢弃，不集中补发。
- 提交使用幂等确认，不伪造用户消息；主动台词进入共享会话记录，并在同一事务中加入QQ持久化同步队列，发送到已绑定的QQ会话；重复确认不会重复入队。尚未绑定的QQ目标不补发旧记录。

提示使用当前角色设定（最多3500字符）与最近4条文本（每条最多400字符），不带历史图片；鼓励自然、亲近的短招呼，也允许输出「[等等]」跳过，禁止假装看到了屏幕或环境。输出最多350 tokens，单次超时60秒。保存返回的用量，但这不是下一阶段自主探索的累计 token 钱包。

## 中文名字唤醒

点击「叫名字」开启，默认关闭，每次启动需要重新开启。支持：

- 小糖人在吗
- 小糖人小糖人

唤醒后等待界面进入通话，再说正文；暂不支持一句话中无停顿地接上正文。唤醒只开启当前语音对话，不扩大主动闲聊许可。

关键词检测在本机 sherpa-onnx 中运行，16kHz PCM仅在内存和本地连接中流转，不保存环境音、不将唤醒前音频发送给云端。命中后复用现有本地ASR与通话；识别后的聊天文本仍会调用配置的聊天模型。模型或麦克风异常会明确提示，不自动切收费语音服务。

麦克风在录音、通话、朗读时暂停关键词检测，避免多路占用与自身语音触发；隐藏桌宠时停止，重新显示且开关仍开启时恢复。唤醒后8秒无转写结束通话；收到转写后保留120秒超时保护，回复完成后的尾随等待25秒。桌宠本地ASR的短句尾停顿改为0.9秒，其他入口维持2秒；使用现有端点检测，没有新增Silero VAD。

### 模型与来源

本机已有 sherpa-onnx 1.13.8、onnxruntime 1.30.0、本地ASR和Piper。额外安装官方中文KWS模型，文件位于 `backend/data/asr/sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01`，数据文件不进入Git。

- 官方说明：https://k2-fsa.github.io/sherpa/onnx/kws/pretrained_models/index.html
- 下载：https://github.com/k2-fsa/sherpa-onnx/releases/download/kws-models/sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01.tar.bz2
- 归档大小：32,654,866字节。
- SHA256：`b2f7c89690dc8ce4c6ed6afeab7cd800c36ad1421fb6b6302b4a4b194cf7f35f`。
- 使用epoch99的int8编码器、解码器、连接器，单线程；阈值0.3、关键词分数1.5。关键词文件 `backend/app/services/pet_wake_keywords.txt`。分发时须遵守上游许可。

## 验证与部署

已通过：后端主动队列6项、桌宠状态机8项、本地语音11项、语音通话11项、QQ ASR回归1项；Vite构建通过。真实Electron测试覆盖队列送达、PCM经IPC/WebSocket触发模拟唤醒并接入通话、关闭麦克风，以及原有流式回复、播放、打断、换模型外观和重载。

官方KWS模型已用本地合成的两个唤醒短语命中测试，普通句子与静音未命中；不等同于真人远场、噪声与回声验证，仍需实际试用调参。测试没有调用付费模型。

需要重启后端和桌宠加载代码；本次不自动重启正在使用的实例。核心实现：`backend/app/routers/pet_companion.py`、`backend/app/services/pet_wake.py`、桌宠 `electron/presence.cjs`、`src/petWake.js`。


## 2026-10-21 热情陪伴调整

按用户偏好新增「常来找我呀 · 全天留言」：明确选择一次后跨重启保持，不限时，凌晨也可留言；麦克风开关不随之开启。原有忙碌、休息、悄悄陪着及醒来缓冲仍有效。桌宠需运行且显示，聊天或通话时让路。

此节取代上文旧频率：首次初始化等待90秒（另加轮询与生成耗时），同会话20分钟、同角色40分钟，全局每天最多16次生成尝试。未回应仍可留下后续消息，不要求用户回复来解锁；失败和主动跳过仍占次数，不自动重试。已有冷却到期时间不回溯缩短，下一轮按新间隔计算。QQ继续通过已有绑定同步，不另发通知或声音。
