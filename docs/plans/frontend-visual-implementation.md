更新：2026-10-18。用户已正式授权修改前端。本轮不改后端、数据库、模型接口协议，也不部署或提交代码。

## 已落地

- 正文寒蝉圆黑体、角色姓名站酷快乐体、功能标题源泉圆体粗；完整字库转 WOFF2，不裁减用户输入所需的中文字符，保留字体许可证。四个字体文件由约 36.3 MB 压缩至 21.5 MB，按浏览器字体使用情况加载。
- 玫瑰棉糖、奶油烘焙、夜间星轨三套主题，独立于日夜模式；本机保存，主题面板支持外点及 Esc 关闭。入口前预读配色/日夜设置和轻量背景，降低首屏白闪。
- 顶部「糖人之家」无英文翻译，保留导航的中英层级、W2 弧线星点和原有大脑健康/重启控件，不提供标志试选菜单。
- C2 角色聊天邀请、H2 聊天细标题、T2 更多工具固定为选定方案，不带入 Demo 的试选路由、mock、示例角色或后端请求拦截。
- 角色主视觉：人物居左、介绍在右，读取真实角色卡和当前形态；原有完整档案、编辑、删除导入卡、开场白、形态及 Live2D/VRM 功能仍可从档案区使用。画面上新增的模式控件、轮播标题/编号/翻页按钮、真实画廊的描述和状态标志移到图外。
- 真实画廊图片支持拖动、上下/左右位置、缩放、完整显示/填满，以及取消、重置、保存；桌面与窄屏各自保存。视频和私密层仍保留原有查看/管理路径。
- 头像选图支持方形裁剪、拖动与缩放，生成 512×512 头像，再交给原有角色保存流程。
- 聊天候选独立于输入 footer；收起等于停用，本轮仍为本地静态建议，无候选生成模型请求。附件在候选左侧，紧凑图标；按住说固定在左、文字框占满剩余宽度、发送垂直居中。保留发送/粘贴附件、流式、落库、导入卡和记忆等既有逻辑。
- 聊天常用入口顺序：成员、模型设置、提示词、无审查；其他工具进入更多。删除重复通话、生成和自动朗读入口；右栏语音/视频通话入口明确提示功能尚在规划，单条消息朗读保留。
- 私人空间的巡检和个人数据库默认折叠，展开才挂载面板；原有个人档案、身份切换、长期记忆入口仍保留。

## 小窝信息架构

| 分区 | 内容 |
| --- | --- |
| 共同回忆（默认） | 真实共用画廊、页头小贴纸管理 |
| 一起玩 | 后端功能注册表、搜索筛选、最近项目、工作台 |
| 小窝动态 | 独立功能的真实产出与反馈 |
| 小窝设置 | 外观与入场 / 小窝大脑 / 功能偏好 / 运行与日志 / 共用世界书 / Agent 协作 |

保留已定 N3 居中页头和角色贴纸。设置一次展示一个类别；Agent 收件箱只在进入对应分类时读取。最新桌宠、QQ 桥、日语/英语等独立面板和功能偏好去重名单保留，没有用旧 Demo 覆盖。

「共同回忆 → 页头小贴纸」可分别选取公开共用画廊图片、恢复默认或隐藏。自选图的构图设置可调整；保存的是浏览器偏好，不修改原画文件。删除、改归属、转私密或无法核实可用性的自选图不显示在页头。默认两张贴纸是用户已审阅的现有素材，保留素材本身内容，不冒充新绘互动动作。

## 本机存储

- `xtr.theme`：沿用原日夜模式。
- `xtr.visual.palette`、`xtr.visual.icons`：主题与图标样式。
- `xtr.visual.gallery-composition-v1`：按图片 URL + wide/narrow 保存构图，未写入数据库；同图在画廊和贴纸使用相同位置比例，但画框比例不同可能导致显示范围不同。
- `xtr.visual.nest-stickers-v1`：左右贴纸的画廊 id 与隐藏设置；每次核实公开归属，不存私密图副本。
- `xtr.visual.suggestions-enabled`：候选开关。
- `xtr.visual.boot-enabled`、`xtr.visual.boot-character`：仅入场偏好，**尚未接入实际启动播放**。

配置只在本机浏览器生效，不承诺账号间或设备间同步。保存失败会在构图/贴纸设置里提示。

npm run test:stream
npm run test:visual -- "C:/Program Files/Google/Chrome/Application/chrome.exe"
