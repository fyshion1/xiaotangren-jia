## 本体实际保留的能力

- 单聊、群聊、会话与消息持久化，基础身份与角色管理，模型连接与请求组装。
- 原生记忆：原文归档、候选整理、人工审核、长期记忆、检索、注入与管理界面。可选本地向量依赖/模型未随测试副本复制，缺模型时不能将关键词检索误报为语义检索。
- 附件、图片、画廊、用户资源层、存储管理及备份相关宿主接口。
- 插件管理、开关应用、入口隐藏、可恢复卸载、角色包导入与固定插件宿主契约。
- 通用中性 UI、基础外观预设、明暗模式。
- 仍有语音、媒体、生图、提醒、QQ/桌宠等接入与配置宿主代码，以及部分扩展面板/适配代码。本体不是只剩聊天 API；不是所有相关业务实现都已经物理迁出。
- 个人资料的通用数据服务仍在本体；未安装/关闭相应插件时阻止额外档案或数据库来源读取。第三方插件完整权限沙盒、通用记忆后端热替换未实现。

## 如何验收

1. 日常实例继续使用原端口和原数据。不要通过删除当前角色或私人文件模拟新安装。
2. 本轮另建本机临时验收副本：只复制宿主源码和前端静态资源，`features/` 为空；未复制 `.env`、模型密钥、个人文档、聊天、记忆或用户上传素材。
3. 测试服务仅监听 `127.0.0.1:8001`，静态前端与 API 同源；精确本机目录记录在被忽略的 `backend/data/core-check-workspace.json`。目录内提供启动与停止脚本。
4. 测试副本复用原环境的 Python 依赖和 Node 构建依赖，不是独立可分发安装包。首次只有一个“助手”和一个“用户”，插件列表为空，个人资料 API 返回 409，原生记忆 API 可用。
5. 在设置 → 设置分区 → 模型连接自行配置模型；未自动复制原实例密钥，未调用付费服务。云端模型会接收主动发送的消息及参与请求的上下文，空插件不等于全离线。
6. 先验收单聊/群聊、身份/角色创建、刷新持久化、记忆候选与审批、配色/明暗、附件与删除、手机布局；再单独安装插件验证安装/关闭/重启/卸载与数据保留。真实模型和语义检索需配置后人工测试。
