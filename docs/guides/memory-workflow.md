# 个人双库与每日事件记忆

2026-10-20 新增按需/常驻/暂不注入的明确选择、2400 字符共享正文预算、自动候选首次生成满 24 小时过期（可恢复/保留待审）、手动 AI 事件整合及自动整理短时间合批。旧候选不追溯清理。范围、费用与重启边界见记忆负担优化（不随内核分发）。

2026-10-19 新增「当天经历与来源」统一管理。功能活动上报、秒级跨来源时间线、近期原文检索、来源开关及统一轮次已接入；实际范围见 总体方案施工结果（不随内核分发） 与 [共享活动契约](../integrations/feature-memory-api.md)。

私人空间保留「个人记忆库」「个人数据库」双栏。前者记录生活经历、共同羁绊、约定与愿景；后者保存现实个人事实。聊天页「记忆」只查看短期上下文与最近实际发送，不需要勾选消息。

## 个人记忆库

01_源记忆 → 01_清洗层 → 02_AI记忆处理层 → 03_长期记忆池/待审核 → 人工核对 → 03 正式记忆。

- 聊天文本、图片、视频自动全量保存在 SQLite 与本地附件库，不做价值筛选。短期上下文窗口大小只影响下一轮发送，不删除本地聊天。
- 01 按「身份/功能/会话/YYYY-MM-DD.md」归档；北京时间每天一份，消息精确到秒并按时间排序，图片和视频链接指向本地原文件。群聊保留发言角色。视频原文件及关键帧均持久化，可在刷新后继续使用。
- 清洗层只处理派生副本：去 HTML/界面操作标签、助手冗长动作描写、识图和 API 调试，保留关键原话、时间、角色、附件关联。原始记录不变。
- 02 自动提炼当天事件，包括对象/岗位、情绪变化、事实纠正、应对方式及新的共同愿景。日常一次性事件也可记，不要求“记住”等触发词。自动处理新增消息，并携带已有事件摘要衔接；首次处理或显式重新整理时按预算分批覆盖全天，不只取最后几轮。
- 03 直接显示「小时级发生时间＋摘要」。小三角展开具体经过；可以编辑摘要、细节、时间、角色范围、生命周期与注入开关。待审核与已批准在同一时间轴展示；未批准不会注入。用户编辑过的条目不会被自动重整覆盖。
- 姓名默认不脱敏。编辑时可以选择注入脱敏并调整姓名→称呼映射；原文保留，只替换送给模型的内容。
- 模型只应依据用户原话和实际附带图片确认岗位、联系人等事实，不能根据助手的安慰或自称看见图来猜。真实总结质量仍取决于所选模型。

「02 AI 处理」显示每天的整理状态、重新整理按钮、可选整理模型及长期索引设置。模型留空沿用聊天的视觉模型和同一通道配置。模型被 Gemini PROHIBITED_CONTENT 等规则拒绝时，显示“模型拒绝处理”，原文和附件保留；不自动绕过上游限制，不对同一批内容循环重试。更换适合的模型后可以显式重试。普通新消息会自动接续整理，关闭页面不会取消已经启动的后端整理；重启后未完成批次可在这里重试。

## 个人数据库

01_源资料 → 02_AI工作层 → 人工核对 → 03_AI注入层。稳定的真实个人信息可由聊天整理进入事实候选，但求职经历等生活事件仍属于记忆库。双库共同服务提示词。

## 存储与迁移

删除入口迁到「糖人小窝 → 小窝设置 → 左栏：存储管理」，有「聊天记录」「图片与视频」两页。支持选择会话、分页查看、选择删除和确认。删除消息同步更新 01 日归档及清洗副本，并回收未被其他消息引用的附件；正式记忆独立管理，避免删除聊天就误删用户核对过的结论。

旧版哈希 JSON 散片迁到隐藏的 .旧版源记忆备份，合并到按天归档。原 SQLite 记录不会被删除或自动批准。旧长期记录在个人记忆库「旧记忆」中保留，可以提交审核。个人记忆库已加入 Git 忽略。

## 检索与验证

QQ 桥的单角色和「群聊」模式均复用当前记忆流程。「群聊」跟随 `group_roster`，QQ 私聊与 QQ 群消息都进入所选用户身份的 `group` 会话；未指定身份时跟随当前身份。单角色私聊进入 `single-<角色>`，单角色在 QQ 群的既有群会话位置保留，仅由该角色开口。提示词按身份与在场成员筛选已批准且启用的长期记忆。

原文与附件先持久化，回复计划不入助手历史；QQ 确认实际送达后，按气泡保存文字、发言角色和真实图片。被打断或发送失败的尾段不作为已经说过的话。整理仍进入 01 归档 → 清洗 → 每日事件 → 人工审核启用，不调用旧攒轮次提炼；`memory.enabled` 只控制自动整理。表情外形、动作和情绪标注是 `qq_sticker_catalog` 媒体派生数据，不调用旧“记住图片/视频”功能，不直接写入长期记忆。

短期按最近消息窗口携带顺序和图片/视频帧；长期先过滤批准、身份、角色、功能及生命周期，再做向量＋关键词检索，核心羁绊/愿景在预算内常驻。向量是可重建索引，不决定权限。无身份调用不注入个人长期资料。文本文件是正式记忆来源，SQLite 保存原始聊天、进度、开关和向量缓存。

测试：backend/tests/test_memory_workflow.py 覆盖按天排序、清洗、无触发词事件、拒绝保留原文、增量整理、用户修改优先、脱敏开关、视频帧持久化与级联删除。frontend/tests/memory-workflow.mjs 覆盖双栏、展开编辑、批准但不注入、存储入口及手机布局；全部 API 被拦截，不写真实资料。
