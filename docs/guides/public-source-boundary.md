# 源码发布边界

Shionarium 公开仓库用于分发通用框架源码、通用文档和合成测试。

- 私人角色设定、作者规划、个人项目要求和本机问题记录应存放在仓库之外。
- 主题和角色包使用独立插件或发行组合管理，不把作者使用的数据作为新用户的默认资料。
- 聊天、账号、密钥、上传文件和个人资料库属于本地运行数据，不提交 Git。
- 调研快照、截图、模型实际输出和评测运行记录可能含私人内容，默认不提交。评测代码、明确合成的测试案例与配置样例可以保留。

提交前执行 `python tools/check_public_tree.py`。CI 使用同一检查阻止已知私人目录重新进入当前源码树。该检查仅覆盖列出的路径规则，不代替逐项内容审查、密钥扫描或完整的 Git 历史审计。

从当前版本删除文件不会清除此前提交中的内容。普通克隆可能仍下载历史对象，旧提交、标签、分支、他人克隆和缓存也可能保留副本。处理历史需要单独审查和协调；若发现凭据，应先撤销或轮换，不能仅依赖删除文件。
