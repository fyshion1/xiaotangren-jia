# 小工作室：项目、后台审批和隔离工作区

2026-10-19。项目与审批、受控网页读取、Docker 隔离执行及工作区 Codex CLI 已接入。本机 Linux 引擎、基础镜像与独立 agent 镜像已就绪。Claude Code 尚未接入。

## 使用路径

在“小窝设置 → 自主活动与沙盒”查看活动记录、独立时钟与钱包，以及“小工作室 · 项目与后台审批”，入口与外观、进程管理并列。可直接打开 `/#autonomous-activity`。全局后端独立调度，不依赖 QQ 在线状态、互动机会或未回复状态；QQ 是可选通知插件。先配置钱包，再启用独立活动。详见[独立钱包、元认知与通知](autonomy-wallet.md)。

小糖人可以提出项目、保存进度、申请继续，并用现有私聊渠道向主人表达愿望。聊天中的“好”“我同意”不会生成授权；不解析聊天文本为额度配置。后台展示申请理由，由主人填写追加 token、有效小时以及文档、公开网页只读、隔离 Python、工作区 Codex 权限，再点击“批准本次资源”。

批准绑定主人身份、角色和项目，每笔 1,000–200,000 token，有效 1–24 小时。文档权限必选；网页、Python 与 Codex 单独选择。批准替换同项目旧授权，已用和未知用量不会清零；拒绝或重复提交不会生成多笔授权。授权仅在后续新的自主活动开始时绑定，不能升级正在进行的普通活动。每位角色最多十个进行中项目；滚动 24 小时内最多提出三笔资源申请，同一项目被拒后休息 24 小时，已有待审申请直接返回原申请，不反复创建。项目可以不做完，不会自动批准、续期或补额度。

后台审批写接口仅接受本机请求及专用请求头，拒绝跨站提交；支持本机 Vite :5173 代理。它不是多用户登录系统，不应把本地后台裸露到公网。沙盒本身没有网络或后台访问凭据，模型工具表中没有审批接口。

## 预算与暂停

普通活动使用全局页独立配置的每日及单次额度。后台批准的项目拥有独立的追加额度，多次活动共同扣同一笔授权，不能借用其他角色或项目的余额；同时受对应钱包的累计许可限制。界面分别显示普通和项目支出。全部调用继续写入同一个 `exploration_calls` 账本，先原子预留，再按实际输入＋输出结算。

项目每次活动仍最多六笔模型请求、十分钟、单次最多 50,000 token。全局只允许一笔探索模型请求在途。用量未知或超出预留仍停止当天全部自主模型调用，追加审批不能绕过。工具结果使用本地规则截短后回填上下文，不额外调用模型压缩，原始结果保留在活动或项目记录中。

授权到期、被替换、项目暂停或全局“今天先休息”，均阻止后续模型调用、工作区写入和执行；在途模型仍结算。运行中的容器每 250 毫秒重新检查授权，清理过程可能额外耗时，不能承诺瞬时停止。暂停项目撤销授权并取消待审申请。发布前及每个 QQ 气泡前核对任务是否仍可发布，空间也核对；已生成的项目分享不能绕过随后发生的撤权或暂停。销毁工作区会额外删除该项目保存的文本文件，预算和项目记录保留。

## 工作区与只读源码

持久工作区是每项目独立的 SQLite 文本文件集合，不接受宿主路径。最多 30 个文件、单文件 32 KB、合计 256 KB。拒绝绝对路径、目录穿越、反斜杠、隐藏路径和未允许的扩展名。后台按纯文本查看，HTML/JS 不在宿主页面执行。

只读源码来自筛选快照：`frontend/src`、`backend/app` 和 `features/desktop-pet` 中的部分文本源码。排除 .git、依赖、运行数据、素材、隐藏文件、符号链接/目录联接、配置类文件及可识别的密钥字面量；快照有总容量和单文件限制。它不是包含所有素材、构建配置和依赖的完整项目副本。读取快照不授予修改主项目的权限。

容器中 `/reference` 为只读快照。桌宠源码复制到 `/work/desktop-pet`，在独立 Git 仓库的 `sandbox-experiment` 分支实验，不共享宿主 Git 元数据、远端或凭据，也不包含宿主私密设置和运行数据。持久工作区文件覆盖到 `/work` 对应位置。容器退出即销毁；成功收集的改动文本经宿主重新校验路径、额度和文件配额后存回项目，单轮导出 JSON 最多 24 KB，不导出二进制或删除操作。输出过大、超时或授权撤销时可能无法收集本轮改动，先前保存的文件仍保留。

可运行已保存的 Python 入口，或在单独批准后调用容器内 Codex。容器中可修改文本源码、用 Git 检查差异；没有 Node/Electron 运行环境或新依赖下载能力，不自动合并、安装到真实桌宠或部署成果。查看源码、提出改进意见不要求授予执行权限。

## Docker 准备

安装 Docker Desktop 并启动 Linux 容器引擎后，在项目根目录运行：

```powershell
$env:PATH = 'D:\other software\Docker\app\resources\bin;' + $env:PATH
& 'D:\other software\Docker\app\resources\bin\docker.exe' build `
  -t xiaotangren-sandbox:local backend/sandbox

# 可选的 Codex 能力，基础镜像建好后再构建
& 'D:\other software\Docker\app\resources\bin\docker.exe' build `
  -f backend/sandbox/Dockerfile.agent -t xiaotangren-agent:local backend/sandbox
```

后端需要能在 PATH 找到 `docker`，或使用约定安装路径。镜像构建是宿主准备步骤，模型不能触发；运行时解析本地镜像的不可变 sha256 ID，使用 `--pull=never`，没有自动拉取或自动安装降级。后端位于另一个 Docker 容器的部署方式不自动开放执行，不能为了接入而把 Docker socket 挂进应用。

执行限制：无网络、只读根文件系统、非 root 用户、清空 Linux capabilities、禁止新增权限、0.5 CPU、256 MB 内存且不额外使用 swap、工作区 tmpfs 32 MB、临时目录 tmpfs 16 MB、64 KB 宿主输出上限。Python 最多 32 个线程/进程，子程序最长 25 秒，宿主监督期限 30 秒；Codex 最多 64 个线程/进程，绑定容器 CPU 0，CLI 最长 55 秒，宿主监督期限 60 秒。Codex 的运行时线程池需要额外进程配额，不提高 CPU、内存或总 token 上限。没有可写宿主挂载、Docker socket、模型密钥、QQ 凭据和本机 API；显式清空全部代理环境变量，避免 Docker 客户端自动注入代理凭据。宿主崩溃后容器内部仍有期限保护。执行锁持久化，旧任务先清理才允许启动新任务。

同一授权连续三次执行失败会撤销该授权，留下记录，必须重新后台审批。Docker/镜像未就绪时不能批准执行权限，绝不回退到 PowerShell 或宿主 Python。

## 公开网页读取

只有后台勾选“公开网页只读”的项目才能调用。通过窄代理进行不带登录态、Cookie、Authorization 的 HTTPS GET，不提交评论、点赞、关注、上传或表单。可读取搜索结果与普通网页文字，包含 AI 同人创作等自主兴趣；不是完整浏览器，不支持登录、动态页面、图片理解或视频观看。

获批项目活动不注入私聊、长期私密记忆、私密人设字段或表情库；仅使用公开角色字段、当前角色自己的项目与工作区资料。项目活动只在私聊上下文运行，不把项目内容带入群或空间的规划上下文。分享网页只能引用本次任务实际读取的来源步骤，由程序添加真实返回的网址，模型不能自行编造链接。

只允许 443 端口，每次解析检查全部 DNS 地址，并把 TLS 连接固定到已检查的公开 IP；每次重定向重新检查。阻止本机、局域网、元数据、混合内外网解析、特殊/转换地址。本机代理使用 Fake-IP 时，仅在解析结果全部属于 `198.18.0.0/15` 的情况下通过固定公网 `1.1.1.1` 的 HTTPS DNS 查询真实 A 记录，再执行相同地址检查；不连接 Fake-IP，也不修改系统代理/DNS。限制重定向次数、响应类型、字节数和读取时间。网页和工具输出始终作为不可信资料，不能批准预算、注册工具或修改权限。

## 工作区 Codex

独立镜像固定安装真实 Codex CLI `0.163.0`，不使用宿主 Codex、登录态或订阅额度。后台需单独勾选“工作区 Codex”；未安装对应镜像时禁用选项并拒绝审批。规划器的 `agent` 动作只提交任务文字，不能选择模型供应商、密钥、镜像、挂载、资源限制或额度。

CLI 采用非交互临时会话，只在隔离容器内关闭其内层执行沙盒，真正执行边界由外层 Docker 强制提供。根目录与 `/reference` 仍不可写，所有可写临时空间在容器内部。关闭 CLI 多代理、持久目标自动续跑、远端插件、网页搜索、请求压缩和 WebSocket 功能；不配置 MCP、账号或宿主工具。即使工作区程序修改自己的 CLI 配置，也不能获得外部网络、宿主权限或额外模型额度。

容器保持 `--network=none`。容器内 Python HTTP 中继只监听自己的 `127.0.0.1:8765`，把 `/v1/responses` 的有界文字请求经 Docker 标准输入/输出交给宿主监督器。无发布端口、Docker socket、宿主 HTTP 代理或 API 密钥。宿主把文字、函数工具和 custom 工具转换到已配置 QQ 桥模型的 Chat Completions 接口，然后将实际回复转换成 Responses SSE 交回 CLI。模型返回的命令只由容器内 CLI 执行，宿主从不执行工具命令。

每次请求（包含完整上下文、工具 schema、格式说明）调用统一的原子预留、实际 usage 结算入口；CLI 重试仍占新的一笔额度，最多六次请求包含外层规划与顾问。单次输出最多 600 token，agent 总运行最多 55 秒；超时、取消或供应商用量缺失保守扣账并停止当天自主模型活动。拒绝服务端历史 ID、远端托管工具、图片及未知输入类型，不能用压缩接口隐藏模型调用。CLI 自报 usage 不参与扣账。

12,000 token 授权可能装不下 CLI 的初始完整上下文；此时在调用付费模型前停止，不擅自改额度。即便批准更多项目额度，单次活动仍最多 50,000 token。真实供应商还必须支持函数工具并返回有效 usage；目前验证为真实 CLI、真实容器及模拟供应商，没有通过测试消耗用户付费模型额度。复杂 Responses 功能与 Claude Code 不在本版支持范围。

接口依据 OpenAI Docs 的 [非交互执行](https://developers.openai.com/codex/noninteractive)、[配置参考](https://developers.openai.com/codex/config-reference) 和 [Responses 创建接口](https://developers.openai.com/api/reference/resources/responses/methods/create)。CLI 版本固定，后续升级需重新验证协议与边界，不自动追随最新版本。
