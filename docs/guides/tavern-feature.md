# 可选酒馆插件

酒馆实现位于独立项目 `features/tavern`。宿主不必安装它，普通人设聊天、QQ、
语音和记忆功能不依赖酒馆实现。它不要求专家模式，沿用原有开关权限。

保留原有 `/api/imports/tavern-card/*` 和 `/api/worldbook` 地址。
未安装时这些功能路由不注册；Google Takeout 导入仍由本体提供。
`/api/settings` 返回计算得到的 `tavern_installed` 与有效的 `tavern_mode`，
旧的开启设置不会让未安装的插件变成启用状态。

世界书数据和导入角色档案不搬库、不删除。安装或移除插件后需重启后端并
重新构建前端；前端构建通过 `#tavern/*` 在可选实现和空适配器之间选择。
聊天只在插件已安装且模式开启时调用世界书、规则和卡片显示扩展。

插件源代码被本体的 `/features/*` 忽略规则排除，需要单独备份和版本管理。
迁移没有自动提交、创建远端仓库或推送。

注意：SillyTavern 当前上游许可证为 AGPL-3.0，并非 MIT。插件来源与授权说明
保存在 `features/tavern/THIRD_PARTY.md`，拆目录本身不改变已有代码的授权。
