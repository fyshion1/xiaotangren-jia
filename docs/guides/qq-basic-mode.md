# QQ 桥简化模式

非专家模式提供单账号的聊天入口；专家模式保留完整设置。设置先讲用途，技术参数收在「连接修复」。

## 日常保留项

- 绑定一个机器人 QQ：读取已登录账号，自动填写本机连接地址和 token。
- 你的 QQ 号：确认主人，默认允许主人私聊；其他好友与群通过名单勾选。
- 让谁来聊天：单角色或当前多人角色组；继续使用原有会话与记忆逻辑。
- 群里被 @ 才回复：默认开启，可关闭。
- 听懂语音：QQ 转写加本地兜底、直接本地识别或关闭；依赖检测与可选安装沿用首次接入流程。
- 回复方式：只发文字，或跟随对方语音回复；音色为预设选项。
- 表情包：开启/关闭使用、查看图库、从图库移除。移除不删除原聊天记录图片；不开放识别阈值与模型参数。
- 连接诊断、启动/停止、复制日志。日志可能包含 QQ 号码与聊天原文，分享前自行核对。

「连接修复」保留网关目录、网页密码与网页端口，以及本机 WS 地址和连接 token。通常先保存网页密码，再读取 QQ 自动配置。初次尚未绑定账号时也能保存网页连接设置。

## 实际能力限制

后端拒绝一次保存多个账号、高级字段、远程 WS、云端 ASR 及总是发语音。运行时只下发一个账号，强制使用本机正向连接，停用旧桥本地工具授权、管理命令、主动活动、主动群发和空间发布；公共工具中心的普通模式策略继续生效，仅保留已安装且允许的联网能力。消息分段、节奏和语音额度使用固定常规值，不提供新手调参。

规则在后端生效，不依赖隐藏前端按钮。桥收到 `bridge.basic_mode` 时还会将连接数限制为一；`bridge.selection_required` 时暂停建立账号连接。需要同时更新本体和独立 QQ 桥代码。原生完整运行模式使用上述接入方式；轻量部署仍遵守它自己的传输与语音限制。

## 专家模式退出与数据保留

已有多个账号时，关闭专家模式前必须选择一个保留运行的账号。后端关闭模式、停止旧桥与自主活动，再由用户从 QQ 面板重新启动。未选择时返回明确提示，模式保持开启；旧桥停不下来时明确报错，不宣称已经停止。

其他账号和高级设置不删除，只从简化模式运行配置中屏蔽。修改当前账号不会覆盖其他账号；桥的表情包写回也不会覆盖账号列表。重新开启专家模式会恢复完整配置，原先开启的高级活动设置仍可能生效，请在启动前检查。

已有旧配置但没有单账号选择记录时，简化面板可选择已有账号；确认前暂停多账号连接，不默认挑第一个替用户决定。若原配置是远程连接，应先在「连接修复」改为本机网关。自动配置改变端口后，网关状态检查跟随当前选定账号的实际端口。

## 验证

临时数据库测试覆盖单账号限制、高级权限撤销、数据保留、模式切换选择和本机连接限制；桥测试覆盖连接数限制及等待选择时暂停。浏览器用模拟接口验证手机宽度下的账号选择、自动配置、单账号保存和退出专家模式流程，不发送真实消息、不调用付费模型。
