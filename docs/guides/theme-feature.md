# 可选主题与中性本体

现有小糖人主题与默认设定位于独立项目 features/xiaotangren-theme。它与酒馆、工具、自主活动等可选功能平级。

本次提取覆盖默认角色和身份、默认回复风格、品牌组件、角色专属展示、主题 CSS、字体、静态图片及默认状态文案。本体保留通用档案编辑、基础布局、浅深色切换、聊天和记忆逻辑。其他既有服务的进一步拆分属于后续瘦身，不在本次主题迁移中删除。

后端通过 app/theme_feature.py 的固定本地路径加载默认数据；前端通过 #theme 别名选择实际主题或 src/optional/theme 中的中性实现。安装状态在进程启动和前端构建时确定，安装、移除或更换后需要重启后端并重新构建前端。

空库且未安装主题时，默认创建助手与用户；默认身份仍使用 dalaoda 这个历史存储键，以兼容会话与记忆隔离。移除主题不删除现有数据，不替换用户编辑过的档案。已有档案引用的默认图片、上传附件图片和内嵌图片会保存到用户资源层，关闭或移除主题后继续由本体提供；原素材保留。源文件缺失时保留旧引用并显示待处理项。详见 [用户角色资源](user-assets.md)。

核心代码中的通用布局和语义色变量仍由本体维护；品牌配色及装饰样式由主题覆盖。新主题可实现相同前端导出契约，也可在后续重写中精简这些展示接口。

验证：后端运行 tests/test_theme_feature.py 和 tests/test_character_art.py；前端正常运行 npm run build。frontend/tests/tavern-optional-build.mjs 会在无 features 目录的临时副本中构建，检查主题及酒馆实现没有进入产物，且没有字体或角色素材；额外传入 Chrome 路径可验证中性界面的桌面、手机显示和设置入口。不会移动或停用正在使用的插件。
