# 专家模式与可选自主活动插件

普通模式默认不显示工具中心、进程管理、运行与日志、自主活动与沙盒；功能偏好分类已删除。

在小窝设置底部连续点击版本号七次（相邻点击不超过两秒），输入 `xiaotangren` 开启专家模式。
设置保存在本机数据库，重启后保留。专家模式开启后，同一位置提供关闭按钮；关闭后再次开启仍需要口令。
这是面向开发者的隐藏入口，不是多用户身份验证。设置接口要求本机面板来源和专用请求头，普通设置 API 不能修改它。

## 启动和退出

普通模式忽略以前的启动勾选，双击 `start.bat` 后自动启动前端、大脑以及已安装的 QQ 桥、桌宠和常驻 HTTP 功能后端。
没有安装的功能跳过；扫描、抓取等 `watch` 定时任务不会当成 HTTP 后端自动执行。
专家模式可在进程管理调整下一次启动偏好。自主活动插件是专家专用后台，初次不自动启用，须在插件页面启动，
或者在专家进程管理中勾选下次启动；自主时钟、钱包和项目批准仍遵守各自开关。

所有由主启动器创建的子孙进程属于同一个 Windows Job。叉掉主 CMD、Ctrl+C 或启动器退出都会结束整个服务树，
包括隐藏的功能服务和插件后台。该机制不依赖用户按 Ctrl+C，也不接管用户在其他终端独立启动的无关服务。

## 联网与工具

普通模式仅允许已安装的联网工具，忽略旧配置中的本地文件、写入或其他工具授权。
工具运行包与联网适配位于独立可选项目 `features/tools`，未安装时普通聊天仍可用。
工具中心按插件抽屉展示，联网排第一；四项本地文件工具和目录设置已移除。
联网搜索开关分别位于前端聊天、QQ 桥面板和桌宠；未安装 OmniReach 时不显示。
桌宠自己的聊天框也提供联网开关。三个通道分别保存偏好。
专家模式的工具中心保留完整授权配置；QQ 旧版进程内工具配置被关闭，统一走本体工具策略。
关闭专家模式后，旧请求也不能继续执行非联网工具。

## 独立自主活动项目

项目路径：`features/autonomous-activity`，独立 Git 仓库，不由本体仓库收录。
包含 Python 插件、React 设置面板、Dockerfile、个人工作手册模板和原有离线测试。
前端在插件自己的 `ui` 目录构建，本体只嵌入插件页面；沙盒调度通过通用插件宿主在独立进程运行。
插件使用宿主注入的本机 SDK v1（数据库事务、人物/聊天/记忆、模型调用），不 import 本体实现包。
这与仅用 HTTP 接入的外设不同，是与宿主版本配套的可信本机插件。

未安装或专家模式关闭时，既不显示入口，也不开放插件 API、后台启动和沙盒聊天入口。
关闭专家模式时先撤回执行权限，后台在一秒轮询内开始取消并收尾；已发生的模型调用仍结算，配置和历史数据保留。
原有数据库表、钱包密钥保护与沙盒数据目录不变，不需要清空或重新录入。

## 离线验证

本体：在 `backend` 运行 `.venv/Scripts/python -m unittest tests.test_expert_mode tests.test_launcher`。
插件：将 `backend`、`features/autonomous-activity` 两个绝对路径加入 `PYTHONPATH`，然后在根目录运行：

```powershell
backend/.venv/Scripts/python -m unittest discover -s features/autonomous-activity/activity_tests -t features/autonomous-activity
```

Docker 实机测试仍需显式设置对应测试环境变量，普通离线回归不会执行付费模型、发送 QQ 消息或启动用户的服务。
