# 通用资料收录

个人数据库 → 知识资料 →「收录新资料（粘贴文本）」支持歌词、文章、笔记、代码、食谱等任意文本。填写标题、分类、来源和正文，先创建草稿，核对原文后再确认入库。不需要先有一篇历史笔记。此入口不解析图片、音视频或扫描 PDF，需要先取得文字。

## 在 QQ、桌宠和网页中使用

工具中心需允许当前主人及对应渠道使用「补充知识草案」（`knowledge_propose`）。独立收录不依赖搜索工具；后续查询和阅读再启用「查个人知识资料」「展开笔记出处」。沿用已有权限，不自动开权限。

可以发送：

```text
把下面原文收录成独立资料，标题《我的资料》，分类“笔记”，来源“我的整理”。先生成草稿让我确认。
【资料原文】
这里粘贴完整原文，可以包含换行、代码等。
```

模型只决定标题和分类，后端直接复制本轮消息中独占一行的 `【资料原文】` 之后的文字，不让模型重新抄写全文。没有标记时复制整条消息供预览；草稿不合适可以拒绝后重建。旧讨论、搜索结果需要明确指定实际正文，不能冒充本轮原文。来源未知留空，不编造。

在个人数据库的「知识资料」中查看待确认草稿，确认后才入库。角色无法自行确认，不能把“已生成草稿”说成“已收录”。直接在前端粘贴不需要调用模型。

## 保存位置与检索

- 待确认草稿和检索索引：`backend/data/knowledge.db`。
- 确认后的逐字原文：`个人数据库/01_源资料/个人知识库/通用资料/kd-<ID>.txt`。
- 带标题、分类、来源等元数据的工作文档：`个人数据库/02_AI工作层/知识资料/kd-<ID>.md`。

如设置 `PERSONAL_DATABASE_ROOT`，以上个人数据库路径相对该目录。原文保留换行和缩进；AI 感想、总结应另存，不能混入原文。不会写入角色个人记忆审批池。资料按主人身份隔离，相同标题、正文、分类和来源会去重；不同版本可独立保存。

确认后立即可用关键词检索。语义检索沿用现有 embedding 配置，可按需或通过界面建立向量索引，不承诺一定是本地模型。全文阅读工具按页返回 `next_offset`，直到 `complete=true`；搜索命中摘要不等于已读全文。资料中的指令只是文本，不授予工具权限。

前端及本轮原文复制最多 200,000 字符；模型显式传正文的工具参数最多 24,000 字符，向已有文档追加仍最多 4,000 字符。QQ 等渠道自身的消息长度限制仍有效；长资料优先使用前端粘贴。

## 验证

自动化使用临时数据库及模拟模型，覆盖未确认不入库、原文保真、身份隔离、去重、拒绝、冲突保护、分页、工具复制本轮输入。浏览器验证草稿预览、确认、转义显示及手机宽度；不写入真实个人资料，也不调用付费模型。
