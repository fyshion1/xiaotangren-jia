# Gemini 网页 → 小糖人 test 群聊

只采集你手动开启的电脑浏览器会话当前已加载的文字，不读取 Cookie，不自动打开历史会话，不执行 Gemini 页面里的指令。不需要 Gemini API Key。

## 安装与测试

1. 启动小糖人后端和前端。在电脑本机 `localhost` 页面打开「糖人小窝 → Gemini 网页同步测试」，点击获取同步凭证，选中密码输入框内容并复制。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。启用开发者模式，点击「加载已解压的扩展程序」，选择本文件所在目录 `extensions/gemini-sync`。
3. 打开 Gemini 的已保存会话（网址包含 `/app/会话ID`）。如果安装前已经打开了页面，先刷新该页。
4. 点击扩展图标，把凭证粘贴到扩展，后端地址保持 `http://127.0.0.1:8000`，点击「开启当前会话」。
5. 在小糖人聊天列表打开「test · Gemini」，查看同步。可以在 Gemini 继续说话，页面已加载的消息会自动更新。
6. 点击扩展「停止同步」即可停止。关闭来源标签页或重启浏览器也会停止；切到不同 Gemini 会话需要重新开启。

凭证只存在本机后端数据目录和扩展本地存储中，不要写入共享文件或日志。后端应保持只监听 `127.0.0.1`。

## 实现及限制

- 后端：`GET /api/gemini-sync/pairing` 获取本机配对凭证；`POST /api/gemini-sync/messages` 使用 Bearer 凭证推送文字快照。
- 固定测试会话：`gemini-test`。用户身份切换不改变来源会话键。
- 支持真实角色名的 `**大诗音**：`、`**大诗音：**`、`【大诗音】`、`大诗音：` 署名。无法匹配的文本保留原文，角色名来自项目角色列表。
- 同步处理仅更新消息表和来源映射，不调用模型、embedding、记忆提炼。测试会话界面关闭发送、重新生成和记忆写入操作，其他会话不受影响。
- 优先使用页面原生消息标识。缺失时用用户文字哈希和同文出现次数锚定回答，所以流式回答可更新；这种回退模式下编辑用户提问、加载更早的同文消息可能产生新记录，不能保证版本关联。每次新快照最多 50 条一批。
- `complete=false` 表示生成是否结束尚未可靠判定，不能把“文本短暂稳定”当作模型生成完成。
- 第一版只同步文字，不同步图片、音频、思考区和附件；不跟随来源删除本地记录。删除测试记录前先停止扩展，否则后续快照可能重新导入。
- 网页选择器需要在实际登录的 Gemini 页面测试。若提示“未识别到文字消息”，需要适配页面结构；不读取账号信息。
- 稳定 1.5 秒后推送，最长每 5 秒检查一次；本地聊天列表每 3 秒刷新。持续高速流式输出时会等文字稳定后同步。

首次建议只开启一个来源会话。多个会话会汇总到同一 test 群聊；数据库保留来源 ID，但本阶段还没有按来源会话切换界面。
